02 · Tecnologias

Tecnologias que já utilizei

  • Py

    Python

    Linguagem de escrita simples e fácil de ler. Muito usada em automação de tarefas, análise de dados, inteligência artificial e sistemas web.

  • C#

    C#

    Linguagem da Microsoft, da plataforma .NET. Usada em programas para Windows, sistemas web e no desenvolvimento de jogos com a Unity.

  • C++

    C++

    Linguagem de alto desempenho. Usada onde a velocidade importa: motores de jogos, como a Unreal Engine, sistemas e programas pesados.

  • </>

    HTML

    Linguagem de marcação que monta a estrutura das páginas da web: títulos, textos, imagens, links e seções.

  • { }

    CSS

    Define a aparência das páginas: cores, fontes, tamanhos, posicionamento, layout para celular e animações.

  • JS

    JavaScript

    Dá vida às páginas com interatividade, como o botão de modo claro/escuro deste site. Também roda em servidores, com o Node.js.
